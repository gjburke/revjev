# revjev

Attempting to reverse engineer Jev from TypeSafe. It's an interesting model and I want to figure out how it works becuase they aren't giving any full information on how it works. I think different adaptations of (what I think) is a transformer base, some soft of attention mechanism, are interesting (and probably will be needed).
